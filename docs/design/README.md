# Design

## Purpose

This section defines the overall game structure and the principles that every other system should follow.

## Core Fantasy

The player leads one of two factions, builds a roster of heroes, develops a persistent base, and grows from sending individual adventurers on small missions to deploying twenty-hero forces into endgame sieges.

Progression should feel like the player is building an organization rather than only leveling a single character.

## Core Loop

1. Recruit heroes.
2. Improve the roster.
3. Select content.
4. Deploy heroes.
5. Earn experience, equipment, and resources.
6. Upgrade buildings and professions.
7. Craft and improve equipment.
8. Unlock harder tiers and larger deployments.
9. Repeat with a broader and stronger roster.

## Five-Tier Structure

The game uses five major progression tiers corresponding to hero Levels 1 through 5.

Where practical, other systems should align to the same five-tier structure so progression remains understandable across heroes, content, equipment, crafting, buildings, and resources.

## Design Principles

- Roster growth is a primary form of progression.
- Heroes remain useful throughout the game.
- Earlier content types continue to exist at higher tiers.
- Base development and hero development reinforce one another.
- Crafting supports adventuring rather than replacing it.
- Adventuring supplies resources needed for crafting and base development.
- Incremental systems should reduce repetitive management as the player's organization grows.
- Complexity should increase as the player advances.
- Major rules should be documented before implementation.

## Current Scope

The initial design covers:

- two factions
- six races
- eight classes
- hero Levels 1–5
- roster development
- automatic or largely automatic combat
- six content categories
- base building
- crafting professions
- equipment and consumables
- resource economy
- incremental timers, queues, and offline progress
- progression and balance

## Open Areas

Detailed rules for victory conditions, campaign structure, endgame loops, prestige, monetization, narrative progression, and post-Level-5 systems are not yet defined.
