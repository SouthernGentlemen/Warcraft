# Mage — Arcane

## Identity

- Role: Ranged spell damage / resource control
- Resource: Mana
- Primary stat: Intellect
- Auto-attack: Arcane Bolt — ranged Arcane damage

## Talent Tree

The first talent point spent in this tree selects **Arcane** as the hero's specialization.

All values below are starting implementation values and may be tuned during balance passes.

### Tier 1 — Level 1

Choose 1 of 3.

| Talent | Effect |
| --- | --- |
| **Mana Adept** | Increase maximum Mana by 10%. |
| **Arcane Focus** | Arcane Bolt deals 15% more damage. |
| **Clearcasting** | Arcane Bolt has a 12% chance to make the next equipped cooldown ability cost no Mana. |

### Tier 2 — Level 2

Requires a Tier 1 talent in this tree. Choose 1 of 3.

| Talent | Effect |
| --- | --- |
| **Arcane Momentum** | Using an equipped cooldown advances the auto-attack bar by 20%. |
| **Spell Weaving** | Using an equipped cooldown grants 8% Spell Power for 6 seconds; stacks up to 2 times. |
| **Mana Shielding** | When falling below 40% health, consume 10% current Mana to gain a shield equal to 15% maximum health; 15-second internal cooldown. |

### Tier 3 — Level 3 Capstone

Requires a Tier 2 talent in this tree. Choose exactly 1 of 2.

| Capstone | Effect |
| --- | --- |
| **Arcane Power** | While above 50% Mana, gain 20% Spell Power and generate ultimate-bar charge 15% faster. |
| **Evocation** | Using the selected ultimate restores 40% maximum Mana and grants 20% Haste for 8 seconds. |

Selecting a capstone completes the primary specialization path and unlocks the class's other two talent trees.

## Combat Loadout

This specialization uses its listed auto-attack, exactly 2 equipped cooldown abilities, and exactly 1 equipped ultimate.

Talents modify that shared combat package; they do not add extra active ability slots.
