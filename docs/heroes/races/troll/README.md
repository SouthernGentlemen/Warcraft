# Troll

## Racial Bonus — Berserking

Auto-attacks have a **10% chance** to grant **20% increased auto-attack speed for 6 seconds**.

The effect uses a **20-second internal cooldown**.

The bonus accelerates the auto-attack bar. It does not reduce class ability cooldowns.

## Balance Role

Troll is an attack-frequency racial.

The starting target is roughly **4–5% sustained auto-attack throughput** when the proc is triggering normally.
