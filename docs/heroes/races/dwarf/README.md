# Dwarf

## Racial Bonus — Treasure Finder

After a successful activity, there is a **10% chance** to receive one additional roll from that activity's standard loot table.

The bonus roll cannot produce:

- dungeon or access keys
- quest or progression-critical items
- guaranteed first-clear rewards
- unique one-time rewards

## Balance Role

Dwarf is a progression/economy racial rather than a combat racial.

The bonus roll must stay limited to repeatable standard loot so it does not multiply progression gates or unique rewards.

The 10% proc chance is a starting tuning target.
