# Races

## Purpose

Each race provides exactly one racial bonus.

Racials create flavor and small build preferences without replacing the importance of class, specialization, talents, or gear.

All current numeric values are starting balance targets.

## Alliance

- [Human](./human/README.md) — chance to break hard crowd control once per combat
- [Gnome](./gnome/README.md) — resource-spend refund proc
- [Dwarf](./dwarf/README.md) — bonus standard-loot roll chance

## Horde

- [Orc](./orc/README.md) — Attack Power proc
- [Undead](./undead/README.md) — healing from auto-attack damage
- [Troll](./troll/README.md) — auto-attack speed proc

## Balance Principle

The racials are intentionally asymmetric:

- Human — encounter utility
- Gnome — resource efficiency
- Dwarf — economy/progression
- Orc — burst physical throughput
- Undead — sustain
- Troll — attack-frequency throughput

They should be balanced around total practical value rather than identical DPS contribution.

## Open Areas

- final proc chances and magnitudes
- final internal cooldowns
- precise hard-CC definition
- whether Orc Attack Power converts for caster builds
- whether Dwarf bonus rolls weight all ordinary loot categories equally
