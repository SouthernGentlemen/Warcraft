# Gnome

## Racial Bonus — Resourceful

Whenever this hero spends Mana, Rage, or Energy on an ability, there is a **10% chance to refund 50% of that ability's resource cost**.

For Druids, the refunded resource is whichever resource the current form spent.

The proc should use a short internal cooldown so rapid low-cost abilities cannot generate excessive refunds.

## Balance Role

Gnome is a resource-efficiency racial.

Before internal-cooldown effects, the target expected value is roughly **5% resource efficiency** over time.

The proc chance, refund percentage, and internal cooldown are starting tuning targets.
