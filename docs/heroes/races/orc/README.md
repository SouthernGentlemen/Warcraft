# Orc

## Racial Bonus — Blood Fury

Damaging attacks and abilities have a **10% chance** to grant **20% increased Attack Power for 6 seconds**.

The effect uses a **20-second internal cooldown**.

## Balance Role

Orc is a burst physical-throughput racial.

The starting target is roughly **4–5% sustained physical throughput** when the hero attacks regularly.

Because the racial uses Attack Power, it naturally favors physical Orc builds. Whether caster Orc builds receive an equivalent converted offensive bonus remains an open class/race rule.
