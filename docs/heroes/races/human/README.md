# Human

## Racial Bonus — Every Man for Himself

Once per combat, the first time this hero is affected by hard crowd control, there is a **35% chance** to immediately break that effect.

Hard crowd control includes:

- stun
- fear
- sleep
- incapacitate

Slows, damage-over-time effects, and ordinary debuffs do not trigger the racial.

## Balance Role

Human is an encounter-utility racial. Its value is high when hard crowd control is present and zero when it is absent.

The 35% value is a starting tuning target.
