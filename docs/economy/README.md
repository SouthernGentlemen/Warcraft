# Economy

## Purpose

The economy connects content, base building, crafting, recruitment, and hero progression.

## Economic Goals

The economy should:

- give every major activity useful outputs
- create clear reasons to run different types of content
- provide meaningful resource sinks
- avoid unnecessary currency proliferation
- remain understandable across five tiers
- support offline and incremental play

## Expected Resource Categories

### Currency

Gold is expected to be the primary universal currency.

Additional currencies should only be introduced when they solve a clear progression problem.

### Construction Resources

Base upgrades may require broad construction materials such as timber, stone, or similar resources.

Exact resources remain open.

### Profession Materials

Known categories include:

- metals
- cloth
- leather
- enchanting essences
- enchanting shards
- alchemy essences

## Sources

Resources can come from:

- quests
- incursions
- assaults
- dungeons
- raids
- sieges
- base production
- salvage
- profession conversions

## Sinks

Resources may be spent on:

- recruitment
- hero training
- base upgrades
- crafting
- enchanting
- consumables
- mission preparation
- storage expansion

## Storage

Resource storage may be limited by base progression.

Storage should create progression value without forcing excessive micromanagement.

## Open Areas

Later economy design must define:

- currencies
- construction resources
- resource caps
- exact sources
- exact sinks
- conversion rules
- drop quantities
- costs
- inflation control
- catch-up systems
