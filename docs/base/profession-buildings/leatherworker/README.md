# Leatherworker

## Purpose

The Leatherworker handles leather-based crafting and equipment production.

## Progression

Leatherworking will use five material tiers aligned with the rest of the game.

The exact five leather material names are not yet defined.

## Expected Outputs

- leather armor
- leather equipment
- straps and leather components

Exact recipes, class restrictions, crafting times, and upgrade requirements remain open.
