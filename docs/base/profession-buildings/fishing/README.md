# Fishing

## Purpose

Catch fish and aquatic materials through survival activities.

## Track

- Track: **Survival**
- Owning building: **Survival Lodge**
- Hero rule: one Survival profession per hero
- Change rule: learning another Survival profession replaces only the Survival choice

## Progression

Fishing has authored levels 1–5 in `data/base/profession-buildings/progression.json`. Its effective level mirrors the owning Survival Lodge level.

Assignment timing and drag/drop training are supplied by the shared building-assignment framework in WOWUI-079.
