# Skinning

## Purpose

Harvest hides and leather reagents from defeated beasts.

## Track

- Track: **Gathering**
- Owning building: **Gathering Camp**
- Hero rule: one Gathering profession per hero
- Change rule: learning another Gathering profession replaces only the Gathering choice

## Progression

Skinning has authored levels 1–5 in `data/base/profession-buildings/progression.json`. Its effective level mirrors the owning Gathering Camp level.

Assignment timing and drag/drop training are supplied by the shared building-assignment framework in WOWUI-079.
