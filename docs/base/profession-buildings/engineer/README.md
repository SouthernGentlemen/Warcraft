# Engineer

## Purpose

The Engineer produces crafted technology, devices, and utility items.

## Direction

Engineering is a distinct profession building alongside the Blacksmith, Alchemist, Enchanter, Tailor, and Leatherworker.

Potential outputs may include:

- devices
- tools
- utility equipment
- mechanical components
- specialized consumables

The five-tier material progression, exact item categories, recipes, and building upgrades remain open.
