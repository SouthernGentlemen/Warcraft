# World

## Purpose

This section defines the factions, races, setting structure, and world-facing identity of the game.

## Factions

The game has two opposing factions.

### Alliance

Races:

- Human
- Gnome
- Dwarf

Faction-exclusive class:

- Paladin

### Horde

Races:

- Orc
- Undead
- Troll

Faction-exclusive class:

- Shaman

## Race and Faction Role

Faction determines the player's broad identity, visual language, faction-exclusive class, settlements, and eventual campaign context.

Race determines hero identity and may eventually provide small passive differences, but race should not make otherwise valid heroes unusable.

## Class Availability

Shared classes:

- Mage
- Rogue
- Warlock
- Warrior
- Priest
- Druid

Faction classes:

- Paladin — Alliance only
- Shaman — Horde only

Exact race/class restrictions beyond faction exclusivity are not yet defined.

## World Structure

The game is expected to contain locations or regions associated with content progression.

World structure may eventually determine:

- available quests
- incursions
- assaults
- dungeons
- raids
- sieges
- enemy families
- crafting materials
- faction progression
- unlock order

The exact zone map and campaign structure remain open.

## Current Design Goal

World design should support the game systems rather than forcing unnecessary travel or management complexity into the incremental loop.
