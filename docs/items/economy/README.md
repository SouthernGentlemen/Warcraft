# Economy Items

## Purpose

Economy items are resources used for base development and persistent meta progression.

They represent progression value that is not directly equipped by heroes and is not primarily a profession crafting input.

## Uses

Economy items may be consumed by systems such as:

- base construction
- building upgrades
- progression unlocks
- roster expansion
- long-term account or faction advancement
- other persistent systems that require a resource cost

The exact resource families are not yet defined.

## Separation from Other Item Types

Economy items are separate from:

- Equipment — hero-worn combat items
- Reagents — profession and crafting inputs

A source may award more than one category at the same time, but each item should have a clear system purpose.

## Tiering

Economy resources may be tiered when a base upgrade or progression gate needs tier-specific materials.

Not every economy resource must have five versions. Global currencies or universal resources may remain untiered if that produces a cleaner system.

## Sources and Sinks

Every economy item should have intentional sources and sinks.

Potential sources include gameplay activities, progression milestones, and persistent production systems.

Potential sinks include construction, upgrades, unlocks, and other permanent progression decisions.

The final economy design should avoid resources that accumulate without a meaningful use.

## Inventory Model

Whether economy items exist as physical inventory stacks or as abstract resource balances remains open.

The chosen model should prioritize clarity when players manage a large roster and an expanding base.

## Open Areas

Later economy design must define:

- exact economy resource families
- which resources are tiered
- source activities
- base-building costs
- meta-progression costs
- storage caps, if any
- inventory versus abstract-balance behavior
- conversion or exchange rules, if any
