# Keys & Access Items

## Purpose

Keys and access items control entry into specific activities or encounters.

They are progression and content-access items rather than equipment, crafting reagents, or base-economy resources.

## Initial Uses

The category includes:

- dungeon keys
- encounter access keys
- access tokens
- attunement-style items
- other future items whose primary purpose is unlocking content

## Key Rules

Every key or access item must define:

- the content it unlocks
- the tier at which it becomes relevant
- how it is acquired
- whether ownership is permanent or temporary
- whether it is consumed on use
- whether one key unlocks access for a hero, party, faction, or the full roster

## Dungeon Keys

Dungeon keys are the first committed use of this category.

Specific dungeon-key names, sources, and consumption rules will be defined alongside dungeon content.

## Design Goal

Keys should create understandable progression gates and goals without becoming arbitrary inventory clutter.

If a key is required, the game should clearly communicate where it comes from and what it unlocks.
